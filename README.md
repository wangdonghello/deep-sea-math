# 深海数学探险

面向小学三年级儿童的手机网页版数学与深海生物探索游戏。已确认的设计方向是：通过原创宠物探险任务学习数学，以真实深海生物的 3D 观察作为奖励，并提供家庭账号、错题、进度同步和受控排行榜。

`.superpowers/brainstorm/` 中的 HTML 是头脑风暴视觉预览工具使用的页面片段，不是可独立运行的游戏网页。临时预览服务已结束，页面片段中不保留临时访问令牌。

## 首版方向

- 一次学习约 8–12 分钟，围绕“已知—未知—关系—算式—答案”练习数学思维。
- 12 个真实深海生物图鉴条目，均支持 3D 旋转和基础动作；鮟鱇鱼是重点定制模型之一。
- 家长账号下可建立多个孩子档案，分别保存进度和错题。
- 答错后通过提示和订正继续探险；完成整组题目后获得完整解锁奖励。
- 使用经授权的模型和影像，并核验物种事实和活动深度。
