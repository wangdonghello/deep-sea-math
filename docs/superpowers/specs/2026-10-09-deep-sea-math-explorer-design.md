# 深海数学探险：游戏设计规格

**日期：** 2026-10-09  
**状态：** 设计稿，待家长审阅  
**产品形态：** 面向手机的中文网页版，家庭账号体系，云端保存学习数据

## 1. 产品愿景

为小学三年级、约 8 岁、喜欢宠物养成游戏和深海生物的孩子，设计一款“先思考数学、再探索深海”的每日短时游戏。游戏将数学学习包装为原创深海宠物探险，让孩子在做题、订正和观察真实生物的过程中建立“从已知求未知”的思维习惯。

核心体验承诺：

> 认真完成数学任务，就能继续下潜，发现并观察真实的深海生物。

设计借鉴宠物养成游戏中的任务、经验、技能、属性和探险机制，不使用《洛克王国》的官方角色、图片、音乐、地图、剧情或专有设定。世界观、角色名称和视觉素材均为原创或取得授权。

## 2. 目标用户与目标

### 主要用户

- 小学三年级儿童，约 8 岁。
- 对深海和深海生物感兴趣。
- 熟悉宠物收集、技能、经验和升级一类游戏机制。
- 做作业时需要明确、短时、有反馈的任务目标。

### 家长用户

- 创建家庭账号和孩子档案。
- 了解每日学习情况、题型掌握度和错题类型。
- 设置每日学习时长、题量和排行榜可见性。

### 产品目标

1. 吸引孩子自发开始并持续完成短时数学任务。
2. 练习识别已知条件、未知量及数量关系，而非只记答案。
3. 让孩子认识真实深海生物、栖息深度与生存特征。
4. 通过订正形成可观察的学习进步，而不是以答错惩罚孩子。

### 成功标准

- 儿童可以不经家长讲解，独立完成“接任务—答题—订正—观察—领奖”流程。
- 一次日常任务控制在约 8–12 分钟，可由家长调整。
- 答错后能通过分层提示和相似题继续，不会因一次错误丢失已解锁进度。
- 家长能看到题型级学习趋势和需要帮助的数量关系。
- 首版 12 个真实深海生物图鉴条目均具备 3D 旋转和基础动作，且生物事实及素材授权可追溯。

## 3. 首版范围

### 包含

- 手机优先的响应式网页版。
- 家长账号及多个相互隔离的孩子档案。
- 每日任务、数学题、提示、错题订正、进度同步。
- 深海地图、生物图鉴、宠物成长与徽章。
- 12 个真实深海生物图鉴条目的 3D 可旋转模型及至少一种基础动作。
- 4 种生物的真实影像素材。
- 家庭榜、指定好友榜（可关闭）及个人历史趋势。
- 家长学习报告、时长与题量设置、删除孩子档案。
- 断网时访问已缓存题目及已解锁内容，联网后同步记录。

### 首版不包含

- 实时对战、自由聊天或陌生人社交。
- 复杂宠物战斗、基地自由建造或开放世界探索。
- 全网公开排行榜、付费商城和付费抽奖。
- 50 种以上生物或每种生物多套复杂动画。
- 使用任何未授权的第三方视频、模型、音乐或图片。

## 4. 核心体验与页面

### 主要页面

1. **首页／探险日志**：突出一个今日任务、预计用时、当前进度、目标奖励及地图入口。
2. **题目任务页**：展示原创深海宠物任务，逐题引导“已知—未知—关系—算式—答案”。
3. **提示与订正页**：逐层提供审题、条件辨认、关系选择、列式提示；订正后完成一道相似题。
4. **生物观察舱**：展示 3D 模型、旋转和缩放控件、动作动画、身体部位热点、知识卡及真实影像入口。
5. **深海地图／图鉴**：展示四个深度区域、已发现生物和下一次下潜目标。
6. **错题本**：按题型和掌握状态查看错题，并能重新练习。
7. **排行榜**：展示虚拟昵称、掌握分和近期趋势。
8. **家长区**：孩子档案、学习报告、使用设置和隐私管理。

### 每日学习循环

1. 孩子选择自己的头像／档案，首页显示今日任务。
2. 完成一组数学训练，题目包装为训练、技能、属性、商店或探险任务。
3. 答错时获得分层提示；订正并答对相似题后继续本次探险。
4. 完成当前组全部题目后解锁生物或区域。
5. 进入观察舱，旋转模型、查看特征、播放动作或真实视频。
6. 获得经验、技能点、图鉴卡和掌握分；错题与进度同步保存。

日常题组初始建议为 5 道基础题、3 道应用题和 1 道探测题。题量和预估时间需允许家长调整，并在实际试用中验证。

## 5. 数学设计

### 学习方法

每道应用题尽可能显式练习：

1. 已知哪些条件？
2. 要求什么未知量？
3. 已知量与未知量是什么关系？
4. 用什么算式表达？
5. 答案及单位是否合理？

### 首版题型

- 加减法：多位数加减、差值、连续计算。
- 乘除法：乘法表、乘除关系、平均分、当前课程已学的余数问题。
- 两步应用题：组合经验、技能伤害、道具购买、资源数量。
- 未知数关系：逆向求原数、总数、每份数、份数及相关简单等式。
- 单位、时间和路线：长度、质量、金额、经过时间、下潜距离。
- 规律与数据：属性表比较、找规律和简单条件推理。

题目难度由见习训练师、深海训练师、探险大师三级组成。按孩子年级和家长选择的当前教学进度控制范围；未学过的概念不得作为通关必需内容。答题表现连续正确时逐步增加难度，连续出错时降低难度或补充更基础的例题。

### 洛克王国式包装

使用原创角色和设定包装熟悉机制：

- 经验训练：乘法、除法和反向求未知。
- 技能伤害：加减法及多步计算。
- 属性比较：大小比较、求差和表格读取。
- 道具商店：金额、找零和组合推理。
- 捕捉准备：乘除法、余数和资源规划。
- 探险路线：距离、速度、时间和单位。
- 技能升级：数列和规律。

## 6. 通关、订正与奖励

- 每组题全部完成并答对后，才取得完整生物／区域解锁奖励。
- 首次独立答对获得完整掌握奖励。
- 答错不锁回已探索区域，也不清除已有经验；提示、订正和相似题构成继续完成任务的路径。
- 直接看答案可以继续学习，但不计作独立掌握。
- 对错题标记未掌握、提示后掌握、独立掌握等状态；连续独立答对后才标为稳定掌握。
- 同一已掌握的简单题反复练习不会无限产生排行榜积分。
- 奖励以宠物成长、图鉴观察权限、动画、徽章和技能为主，不依赖随机付费或抽卡。

提示顺序：审题提醒 → 已知／未知识别 → 数量关系 → 算式提示 → 讲解示例。提示不应羞辱或责备孩子。

## 7. 生物与深海内容

### 地图分层

潜水艇基地是地图起点；首版的四个可探索区域为：

1. 暮光区（约 200–1,000 米）
2. 深海区（约 1,000–4,000 米）
3. 深渊区（约 4,000–6,000 米）
4. 海沟区（约 6,000 米以下）

深度是教学用区域范围，不代表每个物种的唯一或完整分布范围。物种可能跨区域活动，知识卡要说明范围、观察记录或个体差异，避免给出过度绝对的深度断言。

### 12 个首版候选生物图鉴条目

首版内容制作以以下 12 个不重复的真实分类单元为候选。地图区域按照经过核验的活动深度范围安排；一个生物可以出现在多个区域，不把栖息深度误写成单一固定值。分类单元低于种级的条目在图鉴中明确标注科或属，不伪装成已确认的单一物种。

| 候选生物 | 候选学名／分类单元 |
|---|---|
| 灯笼鱼 | 灯笼鱼科 Myctophidae（选择有可靠观察资料和模型的代表种） |
| 宝石鱿鱼 | *Histioteuthis bonnellii* |
| 蝰鱼 | *Chauliodus sloani* |
| 安康鱼（鮟鱇鱼；约翰逊鮟鱇鱼） | *Melanocetus johnsonii* |
| 深海蜥鱼 | *Bathysaurus ferox* |
| 吸血乌贼 | *Vampyroteuthis infernalis* |
| 巨型等足类 | *Bathynomus giganteus* |
| 长尾海参 | *Psychropotes longicauda* |
| 小飞象章鱼 | *Grimpoteuthis* 属（选择有可靠观察资料和模型的代表种） |
| 深海大鼬鳚 | *Spectrunculus grandis* |
| 马里亚纳狮子鱼 | *Pseudoliparis swirei* |
| 海沟端足类 | *Hirondellea gigas* |

在订购／制作模型前，内容负责人须为灯笼鱼科和小飞象章鱼属选择可核验的代表种，锁定准确学名、活动深度及资料来源。若授权模型找不到准确匹配的分类单元，该条目必须更换为可核验且可合法建模的候选，不得用相似物种冒充。

### 每种生物的体验

- 中文常用名及学名／分类信息。
- 活动深度范围、栖息环境和已知不确定性。
- 3–5 条适龄知识卡：外形、食物、适应能力及有趣事实。
- 轻量 3D 模型，支持 360°拖动旋转、缩放和至少一种基础动作。
- 可选身体部位热点，解释发光器、触手、眼睛或其他适应特征。
- 真实影像或行为片段（如有授权），并标明素材来源；模拟行为动画明确标注为模拟。
- 与深度、体长、速度、数量或资源规划关联的题目。

### 3D 与媒体资源策略

- 混合制作：4 种重点物种定制 3D 模型，另外 8 种采用经过筛选、确认物种并获授权的模型。
- 约翰逊鮟鱇鱼确定为 4 种定制模型之一；重点呈现可发光诱饵的特写、亮灭动画和游动行为。动画须基于可靠资料制作，并标注为模拟行为。
- 12 种全部具备可旋转模型和基础动作；模型统一灯光、交互和视觉呈现。
- 约翰逊鮟鱇鱼列入首版 4 种真实影像候选；影像是否能公开用于产品须单独核查授权。
- 3D 使用适合移动网页的 glTF／GLB，控制网格、材质、贴图和文件体积。
- 模型、动画、视频按需加载；提供加载反馈、轻量模式和静态预览降级。
- 素材台账记录权利人、来源链接、许可范围、署名方式、修改许可和使用期限。

## 8. 账号、同步与排行榜

### 家庭档案

- 一个家长账号可建立多个孩子档案。
- 每个档案各自保存数学进度、错题、图鉴、奖励和排行榜资料。
- 孩子在已登录的家庭设备上选择头像并使用独立短 PIN 切换档案；PIN 不是支付或身份验证凭据。
- 默认使用虚拟昵称和头像；不要求孩子提供真实姓名、学校、联系方式或精确位置。
- 家长可以重置 PIN、导出或删除孩子学习档案。

### 云端和离线

- 云端是跨设备的正式进度来源；客户端缓存题目、已解锁内容和待同步答题记录。
- 断网时仅开放已经缓存的题目和内容；恢复联网后将记录排队同步。
- 答题事件按唯一事件 ID 幂等写入；服务端校验题目、结果和奖励。
- 解锁进度合并取已达到的最高状态；错题掌握状态按服务端验证的最新有效学习结果更新；排行榜由服务端重新计算。
- 当设备版本或题目版本不一致时，旧题成绩可留存，但不得错误覆盖新的题目掌握状态。

### 掌握分和排行榜

排行榜默认只提供家庭榜、明确加入的好友榜和个人历史趋势；第一版不开放陌生人公开榜或聊天。用户可以关闭排行榜。

初始掌握分权重（用于最近 7 天榜单）：

- 新题最终正确率：60%。
- 新题首次独立答对率：20%。
- 错题订正完成度：10%。
- 学习规律性：10%，连续学习奖励设上限。

重复练习同一已掌握题不重复计入新题正确率。榜单显示虚拟昵称、探险等级和掌握分，不展示错题、失败数或真实身份。掌握分是游戏内激励指标，不作为儿童能力诊断或正式学业评价。

## 9. 实现结构与数据流

### 逻辑组件

- **手机网页/PWA**：账号切换、任务、答题、图鉴、家长区和离线队列。
- **题目与游戏规则服务**：题目内容、提示层级、难度、解锁条件和服务端计分。
- **账号与进度服务**：家长账号、孩子档案、错题、学习记录、解锁进度及权限隔离。
- **内容管理工具**：题目、生物事实、模型、视频、来源和授权信息维护。
- **对象存储和 CDN**：模型、动画和影像的版本化分发。
- **数据库**：账号、儿童档案、学习事件、掌握状态、内容元数据和榜单快照。

### 学习数据流

选择孩子档案 → 加载今日任务 → 本机记录作答事件 → 联网后幂等同步 → 服务端校验并更新掌握度 → 计算可获得奖励与排行榜分 → 解锁生物 → 按需从 CDN 加载模型和影像。

排行榜积分和稀有奖励不得只由客户端决定。云端通信必须使用 HTTPS；账号凭据和服务器密钥不得明文写入客户端或日志。生产托管区域、儿童数据合规要求、隐私告知和家长同意流程需在正式上线前确定。

## 10. 异常与恢复体验

- **答题错误**：展示正向提示和下一步，不用红色失败弹窗或扣除历史进度。
- **网络中断**：显示离线状态；本地保存待同步事件；恢复后自动补传并反馈同步结果。
- **重复提交**：服务端使用事件 ID 去重，避免重复加分或奖励。
- **模型加载失败**：显示轻量模型或静态图，同时保留知识卡和任务完成能力。
- **视频无法播放**：提供重新加载或文字说明，不影响图鉴解锁。
- **账号同步冲突**：由服务端依据事件记录合并；无法自动判断时保留记录并提示家长，不静默丢弃。
- **删除档案**：家长确认后删除或按适用的数据政策处理档案及关联学习数据。

## 11. 验收测试

### 学习和游戏流程

- 新孩子能完成从登录切换到领取任务的流程。
- 正确答题、提示后答题、订正和相似题均能按规则更新掌握状态。
- 全部题目完成后发放正确解锁奖励；答错不撤销已解锁内容。
- 已掌握的重复题不会无限增加榜单分数。
- 题目适配已选年级／学习范围；“已知—未知—关系”提示可理解。

### 生物和 3D

- 每个最终选定物种的学名、深度描述、关键事实及来源均通过内容核对。
- 12 个模型在目标手机浏览器中可加载、旋转、缩放并播放基础动作。
- 定制模型和授权模型的外观、动画及标注符合已批准的来源和许可。
- 低性能或慢网环境下有明确加载反馈和降级方式。
- 真实影像和模拟动画有清楚区分，素材授权和署名可追溯。

### 账号、隐私和同步

- 两个孩子档案之间的题目、错题、奖励和进度完全隔离。
- 离线答题恢复联网后只同步一次，跨设备结果一致。
- 客户端不能自行伪造服务器认可的排行榜分或解锁结果。
- 非家长不能访问其他孩子档案的报告和隐私设置。
- 不在日志、错误消息或分析事件中输出密码、访问令牌等敏感信息。
- 目标 iOS Safari 与 Android Chrome 完成布局、触摸交互和 3D 回归验证。
