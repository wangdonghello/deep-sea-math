# v4.1 设计：语文（1–2 年级）学科扩展

- 日期：2026-11-05
- 状态：设计已确认，待规格审查
- 基线：v4 分支 `6a1b896`
- 范围：v4.1 = 学科框架 + 语文 1–2 年级；数学保持不变；英语 v4.2

## 1. 目标

在现有“数学 + 宠物 + 积分”体系上加入语文，做到：

- 语文有独立的题目模型、每日题组、判分与答题交互；
- 积分、宠物 XP、盲盒券、错题本、家长报告继续共用；
- 一年级先跑通拼音、识字、词语，二年级补阅读与古诗；
- 英语以后复用同一套学科框架，不再另起 App。

## 2. 非目标

- v4.1 不做英语、不做作文/听写/口语评测；
- 不做教材同步（不复制统编教材课文与插图）；
- 不做手写识别、笔顺动画；
- 不做 AI 自动批改主观题；
- 不改变数学题库与现有奖励规则。

## 3. 研究依据与业界实践

- 2022 版语文课标第一学段要求“认识常用汉字 1600 个左右，其中 800 个左右会写”（[课标条目](https://www.kebiao.org/standards/CN-S1-LW-01)）。
- 洪恩识字把单字拆成“玩、认、练、写”，并配“测、复习、绘本阅读”，整套约 1300 字（[产品访谈](https://cn.chinadaily.com.cn/a/202007/29/WS5f213d06a310a859d09dae90.html)）。
- 读写类 App 的实验研究综述发现：**内置朗读对故事理解与表达词汇有直接正向作用**，过多“点哪儿响哪儿”的热点互动可能分散注意（[Springer 综述](https://link.springer.com/article/10.1007/s10643-026-02326-1)）。
- 自然拼读体系覆盖约 44 个音素，强调听音—发音—拼写联动（[Oxford Phonics World](https://www.oup.com.cn/zh/english-learning/preschool/oxford-phonics-world-refresh-edition)），作为 v4.2 英语的参考。

## 4. 范围与内容模型

### 4.1 学科

```ts
export type SubjectId = 'math' | 'chinese' | 'english'
```

- 数学题默认 `subject: 'math'`，旧题不改字段也能工作；
- 题组事件记录 `subject`，旧事件缺省 math；
- 家长报告、错题本、每日任务按学科筛选。

### 4.2 语文题型（1–2 年级）

| kind | 示例 | 判分 |
|---|---|---|
| `pinyin` | 听音选声母/韵母/声调；“bā” 的声调是？ | 选项 |
| `character` | 看拼音选字、看字选读音、同音字辨析 | 选项/输入 |
| `word` | 组词、量词、近反义、词语搭配 | 选项 |
| `reading` | 20–60 字短文 + 1–2 个理解题 | 选项 |
| `poem` | 补全诗句、作者、诗意理解 | 选项 |

每题必须带：

```ts
interface ChineseQuestion {
  id: string
  subject: 'chinese'
  grade: 1 | 2
  difficulty: 1 | 2 | 3
  kind: 'pinyin' | 'character' | 'word' | 'reading' | 'poem'
  skill: string            // 如 pinyin-tone / character-recognition / reading-inference
  prompt: string           // 题干
  audio?: string           // public/audio/chinese/...mp3
  options?: { id: 'A' | 'B' | 'C' | 'D'; label: string }[]
  answer: { value: string; optionId?: 'A' | 'B' | 'C' | 'D' }
  explanation: string
  hints: string[]          // 2–5 条
  passageId?: string       // reading 必填
  tags: string[]
}
```

短文单独存：

```ts
interface ChinesePassage {
  id: string
  grade: 1 | 2
  title: string
  body: string             // 20–60 字
  audio?: string
  tags: string[]
}
```

### 4.3 内容规模

- 一年级：80 题 + 10 篇短文 + 约 60 条音频；
- 二年级：100 题 + 15 篇短文 + 约 80 条音频；
- 每日 6 题，按 skill 轮换：拼音/识字/词语/阅读/古诗不连续重复；
- 错题进入错题本，次日优先复习。

## 5. 每日流程与奖励

- 学习首页增加「数学 / 语文」切换，两科各一张今日任务卡；
- 语文每天 6 题（约 4 分钟），数学保持 9 题；
- 两科各自完成、各自产生积分与宠物 XP；
- **盲盒券每天仍只发 1 张**：当天任一学科完成即得，避免多学科刷券；
- 自由练习继续可用，半速奖励规则不变；v4.1 先只练数学，语文自由练习随二年级内容一起接入；
- 错题本、家长报告增加学科维度。

## 6. 音频方案

- 构建期从 `audio-manifest.json` 预生成 mp3，统一音色，存 `public/audio/chinese/`；
- 使用真人录音（普通话），按 `audio-manifest.json` 录制并统一响度；
- 页面只存相对路径，手动点击播放，不自动播放；
- 离线可用；总大小控制在 5MB 内，按需加载；
- 授权说明写入 `public/audio/README.md` 与内容校验。

## 7. 技术架构

### 7.1 领域

- `src/domain/chinese/`：
  - `types.ts`：`ChineseQuestion` / `ChinesePassage` / `ChineseSkill`
  - `judge.ts`：选项与文本判分（声调、拼音、汉字输入归一化）
  - `daily.ts`：按 skill 轮换与难度抽题
  - `schema.ts`：内容校验
- 数学 `domain/quiz` 保持不动；语文不进入五步法。

### 7.2 事件

- `SessionStartedEvent` 增加 `subject?: SubjectId`（缺省 math）；
- `session-completed`、`answer-submitted` 不改；
- 积分与宠物 XP 由现有投影/账本消费，不新增奖励事件；
- 盲盒券按“当天任一学科完成”计算。

### 7.3 页面

- `HomeView` 顶部学科切换；
- `ChineseQuestRoute` / `ChineseQuestView`：6 题流程；
- 组件：`PinyinCard`、`CharacterCard`、`WordCard`、`ReadingCard`、`PoemCard`；
- 阅读题同屏显示短文（可折叠）+ 题目；
- 宠物、商店、盲盒、家长报告共用。

### 7.4 内容文件

```text
src/data/content/chinese/
  grade1.json
  grade2.json
  passages.json
  audio-manifest.json
```

校验：拼音声调合法、答案在选项中、阅读题必须引用存在的短文、音频文件存在、每题有 skill/解析/难度。

## 8. 内容生产与版权

1. 按 skill 清单生成草稿；
2. 自动校验；
3. 人工抽检 + 低年级试读；
4. 入库。

- 古诗用公有领域原文；
- 短文原创或改写，不复制教材课文；
- 识字表参考课标常用字表，不复制教材插图；
- 音频使用真人录音，保留录音者同意与署名记录；
- 内容避免恐怖、暴力、成人化表达。

## 9. 验收标准

- 拼音题声调/拼读 100% 正确；
- 每题有 skill、解析、难度；
- 阅读题只读短文即可作答；
- 音频可离线播放、可重播、不自动播放；
- 内容 schema、判分、每日组题单测全绿；
- 家长报告能按数学/语文拆分；
- 现有数学 1133 个测试不回归。

## 10. 实施顺序

1. 学科框架 + 语文题型组件（10 道样例题）；
2. 一年级 80 题 + 10 篇短文 + 音频；
3. 二年级 100 题 + 15 篇短文 + 阅读/古诗；
4. 家长报告与错题本学科筛选；
5. 英语复用框架（v4.2）。

## 11. 风险

- **音频许可**：真人录音 输出商用许可需确认；备选真人录音。
- **内容质量**：拼音声调、汉字多音字、阅读难度是最容易出错的部分，必须人工抽检。
- **内容量**：180 题 + 25 篇短文是主要工作量，工程只占一半。
- **儿童注意时长**：语文 6 题/天，先观察完成率再调整。
