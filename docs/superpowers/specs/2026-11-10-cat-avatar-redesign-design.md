# 小猫伙伴形象重设计

- 日期：2026-11-10
- 状态：设计已确认，待规格审查
- 范围：只重做 `CompanionAvatar.vue` 中小猫的脸部造型，解决与小狗过于相似的问题

## 目标

小猫要一眼能认出来是猫，不再像“尖耳小狗”。保留六种伙伴统一的全身站立、圆润幼崽风和等级成长结构，只增加猫科清晰特征。小狗及另外四种伙伴不得回归变化。

## 方案

采用“圆脸萌猫”的 SVG 专属脸部层：

- 小而清楚的倒三角鼻，放在短小口鼻区域中央；
- 左右分开的圆润胡须垫，不与狗的大块宽吻共用形状；
- 胡须从胡须垫外缘向左右延伸，每侧三根，不穿过鼻口；
- 正常心情的瞳孔为猫科竖椭圆，仍保留高光；
- 耳朵有独立浅粉内耳；
- 尖耳、长弯尾、Lv.10+ 颊毛保留，但颊毛不得遮挡眼、鼻、胡须垫。

小狗继续使用当前宽圆黑鼻、较宽较长的口鼻、垂耳与狗形嘴线。狗不显示猫的三角鼻、胡须垫或竖瞳。

## 实现边界

- 新增/拆出猫脸局部模板，不改共享身体、四肢、爪、尾、成长参数、经验、等级、状态和动画事件。
- 面部绘制仍在 `CompanionAvatar.vue` 内，用 `animalId === 'companion-cat'` 选择猫脸分支；不要另建第二套组件以免重复全身结构。
- 低心情下猫使用半闭眼曲线，鼻、胡须垫、耳内瓣继续保留。
- 保持 `role="img"`、伙伴名称和心情的可访问名称，以及现有点击 tap 回调。

## 验收标准

1. 猫 SVG 有倒三角鼻、两块分离胡须垫、左右各三根胡须、竖瞳与耳内瓣。
2. 狗仍有当前宽鼻/宽口鼻/垂耳；不存在猫专属胡须垫、竖瞳或耳瓣。
3. 六种动物的完整身体、四肢爪、尾巴和成长等级均不改变。
4. 正常/低心情都保持猫科辨识点，面部元素无重叠遮挡。
5. 参数化组件测试覆盖猫/狗差异；渲染猫狗 Lv.1 与 Lv.15 预览并人工检查。
6. 完整 Vitest、type-check、build 通过。

## 非目标

- 不改六种伙伴的其它造型。
- 不改 Lv.1–15 的成长曲线、成长参数或等级奖励。
- 不改宠物房布局、盲盒、商店或宠物互动奖励。
- 不使用外部图片素材或新动画依赖。

## 工作区状态与安全

实现前须查看当前 `git status`。已有未提交改动必须原样保留；只提交本功能相关文件，不执行 reset、stash pop 或覆盖已有改动。

## 自检

- 需求只涉及小猫外观，范围限定到单个头像组件与相应测试。
- 猫与狗的轮廓差异写成可测试的具体要求。
- 成长缩放/低心情/高等级颊毛交互均有验收条款。
- 没有依赖占位、待定的交付项目。

## 用户确认

用户已确认猫脸方向：圆脸萌猫，三角鼻、分离胡须垫、竖瞳；狗保持宽鼻、长吻、垂耳。用户已确认该技术设计。

## 参考

原创 SVG，不复制外部素材。依据用户要求“猫不要像狗”，以猫科面部差异（鼻、吻部、胡须垫、瞳孔、耳内瓣）提高识别度。
