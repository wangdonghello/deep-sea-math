# 六种伙伴初级形态设计

- 日期：2026-11-10
- 状态：待用户审查书面规格
- 范围：将盲盒六种动物设计为可爱、圆润、全身初级形态，并接入宠物房当前伙伴展示

## 目标

六种盲盒动物——小猫、小狗、仓鼠、狮子、老虎、龙——都展示头、躯干、四肢/爪和尾巴，拥有各自容易辨认的动物特征与讨喜表情。当前选中的伙伴要显示对应形象；小鲸鱼继续使用既有 `PetAvatar`。

## 造型风格

采用圆润幼崽风：头部略大、身躯短圆、四肢短小，豆豆眼、腮红与微笑/吐舌表情。主体使用 SVG 图形，不以 emoji 代替角色身体。

| 伙伴 | 主要辨识特征 |
|---|---|
| 小猫 | 三角耳、脸颊胡须、上翘弯尾、肉垫爪 |
| 小狗 | 垂耳、圆鼻、摇尾巴、爪子 |
| 仓鼠 | 圆耳、鼓鼓脸颊、短尾、小爪 |
| 狮子 | 柔软圆鬃毛、耳朵、尾端绒球、爪子 |
| 老虎 | 圆耳、额头与身体软条纹、条纹尾巴、爪子 |
| 龙 | 小角、短腿、胖身体、小翅膀、尖尖尾巴 |

所有伙伴共享统一构图与视觉比例，但颜色、耳朵、尾巴、鬃毛、条纹、角/翅等按动物区分。心情低时保留伙伴特征，只调整成困倦/委屈眼神。

## 组件与数据流

- 新建 `src/features/pet/CompanionAvatar.vue`：输入 `animalId` 和 `mood`，绘制完整 SVG 全身伙伴；点击发出 `tap`，由父页面转调现有宠物互动命令。
- `PetRoomView.vue` 按当前伙伴分流：小鲸鱼使用 `PetAvatar`；盲盒动物使用 `CompanionAvatar`。
- 当前工作区 `PetRoomView.vue` 还没有伙伴选择器；补上由 `ownedAnimals` 驱动的切换器。选中伙伴切换后，名称、等级与 XP 使用该伙伴的投影状态；所有互动命令都传当前伙伴 ID，XP 不可误记给别的伙伴。
- 不修改抽盒权重、每日券、饲养限制、XP 数值与等级曲线。

## 动效与可访问性

- 尾巴轻摆、点击时轻微挤压回弹；`prefers-reduced-motion: reduce` 时禁用。
- 按钮可访问名称包含伙伴名、心情与摸摸提示；SVG 使用 `role="img"` 和清晰名称。
- 低心情改变脸部表情，但不隐藏动物身体/特征。

## 测试与验收

- `CompanionAvatar` 参数化测试覆盖六个 animal ID；每个形象必须渲染四腿、爪、尾巴，以及对应动物专属特征。
- 点击发出一次 `tap`；低心情时具有低落状态样式；减少动画偏好对应 CSS 规则存在。
- `PetRoomView` 测试确认切换伙伴后名称、等级、XP 和头像同步；小鲸鱼仍渲染既有 `PetAvatar`。
- 测试互动事件携带当前伙伴 ID，避免 XP 加到错误伙伴。
- 完整 Vitest、type-check、build 通过。
- 渲染六张 SVG 预览并人工检查：不裁切、不缺肢体、特征清楚、面部不遮挡、体型可爱。

## 非目标

- 不重做宠物等级阶段造型，不改 XP/升级规则。
- 不改变盲盒概率与唯一拥有规则。
- 不重新设计小鲸鱼或宠物房其它 UI。
- 不添加新图像素材、远程请求或外部动画库。

## 风险与约束

- SVG 多组图层容易因坐标遮挡造成“缺爪/尾巴被身体盖住”；通过渲染预览人工检查与结构测试一并把关。
- 当前工作区与最近线上部署状态不完全一致；它含有尚未提交的盲盒事件/投影改动。实现伙伴切换需沿用当前未提交事件模型，不能丢弃或重置这些改动。
- 盲盒动物的各自成长状态与互动回调必须按当前选中的 pet ID 传递，不能误给主宠物加 XP。

## 实施顺序

1. 在当前代码与未提交盲盒投影基础上，补充每只动物的成长状态及必要事件命令边界（若现有 `PetState` 尚未提供）。
2. 创建全身伙伴 SVG 组件与六类装饰差异。
3. 接入宠物房伙伴切换、按动物分流渲染与当前伙伴互动。
4. 编写组件、投影、命令及页面测试，渲染并检查六张预览图。
5. 全套验证；不覆盖/丢弃已有盲盒工作区改动。

## 验收成功定义

孩子在宠物房选择猫、狗、仓鼠、狮子、老虎或龙时，画面中出现对应的完整全身幼崽；能看出动物特征，表情亲切、可点击互动；每只伙伴显示并增加自己的成长值。

## 自检

- 目标、非目标与验收范围清晰；本设计仅做初级形态及必要的当前伙伴接入。
- 伙伴切换后 XP 必须归属正确，已纳入数据流和测试。
- 未提交盲盒代码是前置工作区状态，设计要求保留、不擅自提交或重置。
- SVG 原创绘制，不复制外部角色素材。

## 用户确认

用户确认了“圆润幼崽风”、六种动物辨识点，以及接入宠物房切换流程。书面规格需用户审阅后，才创建实现计划。
