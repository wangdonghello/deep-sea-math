# v4.0 设计：数学学习 + 宠物养成 + 积分商店

- 日期：2026-11-04
- 状态：设计已确认，待规格审查
- 基线：v3 分支 `8e75549`
- 分支：`v4`（从 v3 拉出，不改动 v3 的线上行为）
- 范围：v4.0 = 现有数学题库 + 一只深海宠物 + 积分与经济 + 商店

## 1. 目标

把“每天做一组题”升级成“每天回来照顾一只属于自己的深海宠物”：

- 做题获得积分，积分可以买食物、玩具、装饰；
- 宠物从蛋开始，孵化、喂养、抚摸、玩耍、升级、变形；
- 学习行为是养成的燃料，但宠物本身不惩罚、不死亡、不掉级；
- 复用 v3 的题库、事件日志、错题本、图鉴与家长区，不重做已验证的领域模型。

## 2. 非目标

- v4.0 不做语文、英语；题库扩展放在 v4.1 / v4.2；
- 不做账号、云同步、排行榜、好友、付费、广告、抽卡；
- 不做宠物死亡、饥饿惩罚、断签清零；
- 不做多宠物同时养成（一只宠物，后续可作为 v4.1 内容扩展）；
- 不做实时战斗或复杂模拟。

## 3. 体验与信息架构

### 3.1 四个一级入口（底部导航）

1. **宠物**（首页）：宠物舞台、名字/等级、心情与饥饿、积分余额、今日探险入口；
2. **学习**：复用 v3 答题流程，顶部实时显示本轮积分；结算页展示积分明细与宠物成长；
3. **商店**：食物 / 玩具 / 装饰三类，固定货架、明码标价；
4. **图鉴**：保留 v3 图鉴；错题本入口放在学习页底部；家长区仍在档案页。

### 3.2 每日循环

打开 → 宠物打招呼并给出“有点饿 / 想玩”的提示 → 点「今日探险」做一组题（答对即时 +1 分）→ 回宠物房间结算（整组 +5，正确率 ≥80% 再 +3）→ 用积分买食物/玩具 → 喂食、抚摸、玩耍 → 获得成长值与心情 → 升级或变形 → 第二天再来。

### 3.3 明确不做

饿坏/掉级/死亡、广告、付费、抽卡、排行榜、断签惩罚、限时抢购。

## 4. 宠物：好看与好玩

### 4.1 业界参考与取舍

| 参考 | 借鉴 | 不借鉴 |
|---|---|---|
| Tamagotchi | 蛋 → 幼体 → 成体的清晰进化、状态可见 | 死亡与“照顾失败”惩罚 |
| Pou | Q 弹挤压、表情、单指互动 | 高频数值维护 |
| Neko Atsume | 低压力陪伴、收集装饰 | 随机到访机制 |
| Finch | 温和语气、把照顾自己变成正反馈 | 真实时间绑定的任务 |
| Pokémon Amie / Refresh | 直接触摸、喂食、玩耍的即时反应 | 复杂亲密度数值 |
| Duolingo | 连续天数与里程碑 | 断签惩罚、排行榜焦虑 |

### 4.2 生命阶段

| 阶段 | 等级 | 形态变化 |
|---|---|---|
| 蛋 | Lv0 | 轻微摇晃；点击有回应；完成第一组题后孵化 |
| 幼体 | Lv1–4 | 大头、短身、眼睛占比大；会跟随点击转头 |
| 少年 | Lv5–9 | 身体拉长，出现斑点/鳍纹；解锁“玩耍” |
| 成体 | Lv10–14 | 体型更大，解锁第二套配色与装饰位 |
| 完全体 | Lv15 | 最终形态、发光轮廓、专属称号 |

### 4.3 视觉规格（程序化 SVG，不依赖外部美术）

- 舞台：深海底色 + 光束 + 气泡粒子；宠物居中，下方柔和投影；
- 分层：阴影 → 身体渐变 → 腹部高光 → 鳍/尾 → 眼睛（含高光）→ 腮红 → 装饰；
- 配色：深海青蓝为主，暖色（珊瑚橙/奶油白）作腹部与点缀，保证深色背景上的对比度；
- 动画：
  - 待机：3 秒呼吸起伏、4–7 秒眨眼、眼睛追随指针/触摸点；
  - 点击：挤压回弹（squash & stretch）+ 气泡；
  - 喂食：张嘴、咬合、碎屑粒子、满足表情；
  - 抚摸：眯眼、飘心、轻微摇摆；
  - 玩耍：玩具弹跳、宠物追扑；
  - 升级：光圈扩散、星星粒子、阶段形态过渡；
- 声音：v4.0 不做音效；v4.1 再用 WebAudio 合成（默认开启、首次交互后播放、可静音）。

### 4.4 好玩的关键交互

- **直接触摸**：手指按住宠物会跟随、蹭手；连续抚摸触发不同表情；
- **喂食**：从背包拖食物到宠物嘴边，或点“喂食”自动播放；
- **玩耍**：点玩具后宠物追扑，连续点击有连击反馈；
- 每日小愿望：v4.1 再加（按日期确定、不随机、不提供数值奖励）；v4.0 先不做。
- **装饰可见**：买到的窝、灯、背景直接改变宠物房间；
- **台词系统**：按状态（饿/开心/刚升级/连续多天）挑选台词，温和、不说教。

### 4.5 成长数值

- 喂食：+8～15 XP（按食物档位），每天最多 3 次；
- 抚摸：+2 XP，每天最多 5 次；
- 玩耍：+6 XP（需玩具），每天最多 2 次；
- 每日首次完成题组：+15 XP；
- 升级曲线：`Lv N → N+1` 需要 `40 + 15N` XP；从 Lv1 到 Lv15 共需 2135 XP，按每天 40–60 XP 计算约 5–8 周。

### 4.6 心情与饥饿（轻衰减、不惩罚）

- 范围 0–100，每小时衰减约 2 点，离线按时间补算；
- 低于 40 时台词变为“有点饿 / 想玩”，外观略没精神；
- **不影响 XP、不掉级、不生病、不死亡**；
- 喂食按食物档位 +30 / +45 / +60 饥饿、+10 心情；抚摸 +8 心情；玩耍 +20 心情；
- 每日互动次数上限用于避免长时间停留，而不是惩罚。

## 5. 积分与经济

### 5.1 积分获取（防刷）

| 来源 | 积分 | 限制 |
|---|---|---|
| 独立答对一题 | +1 | 仅首次独立答对；同一道题每天只计一次；用提示/看答案不计 |
| 完成整组每日题 | +5 | 同一题组每天只结算一次 |
| 独立正确率 ≥80% | +3 | 与整组奖励同次结算 |
| 错题订正 | +2/题 | 每天最多 5 题（+10 封顶） |

一天中等水平约 15–18 分。积分是货币，不与成长值混用；同一道题跨天再次独立答对可以再计一次，但同一天内不重复。

### 5.2 孵化

蛋在完成第一组每日题后**自动孵化**，不收费、不设概率；商店不卖孵化道具，避免把“开始养宠物”变成付费门槛。

### 5.3 商店（固定货架）

| 分类 | 示例 | 价格 | 效果 |
|---|---|---|---|
| 食物（消耗） | 海藻饼干 / 磷虾布丁 / 深海蛋糕 | 5 / 10 / 20 | +8 / +18 / +40 XP，回复 30 / 45 / 60 饥饿（越贵每分 XP 越高） |
| 玩具（永久） | 发光球 / 珊瑚摇铃 / 气泡机 | 30 / 45 / 60 | 解锁“玩耍”，每次 +6 XP |
| 装饰（永久） | 海草窝 / 贝壳灯 / 珊瑚背景 | 40 / 55 / 80 | 改变宠物房间外观 |

### 5.4 经济原则

- 只进不炒：物品不可转卖、无利息、无随机、无限时抢购；
- 每天收入约够 3 份基础食物，或攒 2 天买一个玩具；
- 余额不足时按钮置灰并提示“还差 X 分”。

## 6. 数据与事件

### 6.1 新增事件（追加型）

- `pet-adopted`：领取蛋（含宠物物种、名字）；
- `pet-hatched`：孵化；
- `pet-fed`：食物 id；
- `pet-petted`：抚摸；
- `pet-played`：玩具 id；
- `item-purchased`：物品 id、价格。

### 6.2 投影（全部派生）

- **积分余额** = 答题/完成/订正产生的积分 − 购买花费；购买时校验余额；
- **成长值与阶段** = 喂食/抚摸/玩耍 + 每日首次完成奖励，按阈值计算；
- **心情与饥饿** = 最近互动时间 + 时间衰减（读取时计算，注入时钟保证可测试）；
- **背包** = 已购 − 已消耗（食物）；玩具/装饰永久；
- **每日次数** = 按 UTC 日期统计，跨时区不漂移。

### 6.3 与 v3 的兼容

- 现有档案首次进入 v4 时补一条 `pet-adopted` 迁移事件；宠物积分与成长只结算该事件之后的学习记录，v3 历史不补发；
- 题库、图鉴、错题、徽章、家长报告全部保留；
- 新代码放在独立模块（`domain/pet`、`domain/economy`、`projections/pet`），不改 v3 判分与出题。

### 7.2 商店 / 背包 / 结算

- 商店卡片显示图标、名称、价格、效果；已购买永久物品显示“已拥有”；
- 背包按食物/玩具/装饰分组，食物显示数量；
- 结算页逐项列出积分（答对/整组/正确率/订正）与宠物 XP，升级时播放过渡动画。

### 7.3 边界情况

- 买不起不可点；余额永远不为负；
- 每日互动/订正上限到点提示“明天再来”；
- 断网、改系统时间、重复点击都不会产生负积分或重复发放；
- 多档案各自独立宠物、积分与背包；
- 无档案时不能进入宠物房间。

## 8. 成功指标

- 次日/7 日回访率（本地匿名统计，家长可关闭）；
- 每日题组完成率；
- 宠物互动次数与喂食频率；
- 家长对“孩子主动学习”的正向反馈；
- 不出现“为了积分刷题/猜题”的异常（正确率与答题时长监控）。

## 9. 测试策略

- 领域不变量：余额不为负、买不起不能买、每日上限、同一题组不重复结算、宠物不掉级；
- 投影重放：同一事件流得到同一宠物状态；时间衰减注入时钟；
- 交互组件：喂食/抚摸/玩耍/购买/升级的关键路径；
- 兼容：v3 档案迁移不丢数据；
- 可访问性：按钮可聚焦、对比度、减弱动画偏好。

## 10. 发布

- v4 独立分支与 `/v4/` 预览地址，不改 v3 线上；
- 先在真实家庭试用一周，看回访与完成率，再决定是否替换 v3 入口；
- v4.1 再接语文，v4.2 接英语，共用同一套宠物与积分。

## 11. 已定假设

- **宠物名字**：v4.0 固定叫“小蓝”，不支持改名与自由输入；候选名与改名放到 v4.1。
- **家长端**：v4.0 沿用 v3 家长区，不新增积分明细页；音效开关放在宠物房间的 ⚙ 里。
- **装饰**：纯外观，不影响积分、XP、饥饿或心情数值。
- **宠物物种**：v4.0 只有一只深海小鲸鱼；后续皮肤/第二只宠物放到 v4.1。
