# v4 宠物等级与升级规则

## 等级曲线

- 升级所需 XP（当前等级 L → L+1）：`40 + 15 × L`
- 累计 XP 达到即自动升级，无需手动操作；封顶 Lv.15。
- 每只宠物独立计算 XP/等级（小鲸鱼与盲盒动物互不影响）。

| 等级 | 累计 XP | 阶段 |
|---|---:|---|
| Lv.0 | 0 | 蛋（孵化前） |
| Lv.1 | 40 | 幼体 |
| Lv.2 | 95 | 幼童 |
| Lv.3 | 165 | 幼童 |
| Lv.4 | 250 | 幼童 |
| Lv.5 | 350 | 少年 |
| Lv.6 | 465 | 少年 |
| Lv.7 | 595 | 少年 |
| Lv.8 | 740 | 少年 |
| Lv.9 | 900 | 少年 |

| Lv.11 | 1265 | 成体 |

| Lv.13 | 1690 | 成体 |
| Lv.14 | 1925 | 成体 |
| Lv.15 | 2175 | 完全体（满级） |

## XP 来源

| 行为 | XP | 每日上限 |
|---|---:|---|
| 完成一组题（数学/语文） | +15（给主宠物） | 每学科每天 1 次 |
| 喂食 海藻饼干 / 磷虾布丁 / 深海蛋糕 | +8 / +18 / +40 | 3 次 |
| 抚摸 | +2 | 5 次 |
| 玩玩具 | +6 | 2 次 |
| 订正错题 | +5（给主宠物） | 5 次 |
| 自由练习答对 | +2（给主宠物） | 无 |
| 首次买玩具 / 装饰 | +10 / +20（给主宠物） | 每件一次 |

## 当前版本是否支持升级

支持。v4 的等级由累计 XP 推导（不是单独存档字段），所以：

- 喂食、抚摸、玩耍、做题后 XP 增加，达到阈值立即升级；
- 宠物房间显示 Lv、当前等级进度条、距下一级还差多少 XP；
- 升级时浮字提示“升级！Lv.N”，跨越 Lv.5/10/15 时提示“进化到少年/成体/完全体”；
- 盲盒动物出生即 Lv.1（40 XP），小鲸鱼从 Lv.0 蛋开始；
- 满级 Lv.15 后显示“已经满级”。

## 已知边界

- 心情/饥饿仍为房间级共享，不随宠物独立；
- 升级没有额外奖励（盲盒券/积分），只提升等级与阶段形象；
- Lv.5/10/15 会切换宠物形象阶段；动物目前只换等级标签，不换形态。
